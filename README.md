# Mahindra Singh Bhartiya - 3D Portfolio

A modern 3D interactive portfolio built with **Next.js** and **Three.js**.

## Features

- 🎨 Interactive 3D Scene
- ⚡ Built with Next.js for optimal performance
- 🎭 Three.js for stunning 3D graphics
- 📱 Responsive design
- ✨ Smooth animations

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/mahi-8755652540/mahindra-singh-bhartiya.git

# Navigate to project directory
cd mahindra-singh-bhartiya

# Install dependencies
npm install
```

### Development

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Build for Production

```bash
npm run build
npm start
```
